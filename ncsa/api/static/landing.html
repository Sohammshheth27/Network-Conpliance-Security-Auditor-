WHAT MAKES IT DIFFERENT

Built to be checked,
not just believed

One file, six stages, nothing executed. Vendor settings land on a 126-field vendor-neutral schema, and what comes out the other end can be traced back to the line that produced it.

HONEST UNKNOWN

A result state for “the configuration does not say”. It carries no risk score, is never coloured as a pass, and coverage travels beside every compliance figure so a device we could barely read cannot look like one that mostly passed.

EVIDENCE ON EVERY ROW

Each finding cites the file and the line it came from. Absence is reported as absence — a setting that simply is not present is never scored as a passing one.

UNKNOWN VENDORS

An unrecognised platform is not an error. It routes to vendor-agnostic detectors, and whatever could not be mapped is deduplicated by setting name into one reviewable queue — one approval covers every instance of that name on every device of the platform.

REGRESSION-GATED LEARNING

Teaching it a new setting re-runs a verified corpus first. A change that would break a known-good result is refused outright and leaves nothing behind.

A SECOND OPINION

Findings are re-derived by an independent method. Where the two disagree the dispute is surfaced rather than quietly resolved in favour of whichever ran last.

REMEDIATION THAT CANNOT LOCK YOU OUT

Ordered, rollback-wrapped CLI. Any step that would sever the only live management path is deferred and flagged, never shipped silently inside the script.

REAL PROVENANCE, NOT SIMILARITY

Four frameworks, one chain of custody

A control maps through published crosswalks — STIG to CCI to NIST to ISO — so every citation can be followed back to its source.

CIS Benchmarks and ISO/IEC 27001 are cited by identifier and title only. Their text is copyrighted and never leaves the machine it was licensed to.

THE POSITION

A tool that cannot say “I don’t know”
will eventually say something false

Most tools report a single percentage. That number only means something beside how much of the device was actually assessed — a config we could barely read otherwise looks like a config that mostly passed.

So UNKNOWN is a first-class result. It carries no risk score, it is never coloured as a pass, and coverage travels beside compliance everywhere the two appear.

WHAT THIS RULES OUT
  • A percentage quoted without its coverage
  • An absent setting scored as a passing one
  • A rule we could not resolve counted as clean
  • A framework citation nobody can follow back
